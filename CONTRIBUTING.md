# Contributing

Use Node 24 and `npm ci`. Run `npm test`, `npm run test:e2e`, and `npm run build` before a change. Install the browser for UI tests with `npx playwright install chromium`.

Keep core logging offline, preserve existing records, and add migration defaults for new state fields. Avoid changing the Android application ID or Keystore aliases. Do not include personal logs, screenshots, credentials, local SDK paths, build caches, or APKs in commits.

Food data must declare serving size and provenance. Do not label indicative recipe values as verified laboratory data. Check data and image licenses before adding material from another project.

AI requests require a user-selected connection. Validate generated IDs and numeric bounds. Recalculate nutrition in code. Preserve completed sets during workout changes, and keep draft/review/apply steps separate.
